# Pogoda lokalna dla Ciebie

Statyczna strona HTML z prognoza pogody, prognoza 7 dni, prognoza 24h oraz animowana mapa opadow, temperatury i wiatru.

## Jak wrzucic na GitHub Pages

1. Utworz nowe repozytorium na GitHubie.
2. Wgraj pliki z tej paczki do glownego katalogu repozytorium: `index.html`, `.nojekyll`, `README.md`.
3. Wejdz w repozytorium: Settings -> Pages.
4. Wybierz: Deploy from a branch.
5. Branch: `main`, folder: `/root`.
6. Po chwili GitHub pokaze adres strony.

## Dane

Pogoda: Open-Meteo. Mapa: OpenStreetMap / Leaflet.

W paczce jest tez `favicon.png`, czyli ikonka sloneczka na karte przegladarki.

Nowa wersja pokazuje tez indeks UV, europejski AQI oraz geste znaczniki temperatury na mapie.
